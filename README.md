# Verilog 4-bit Up/Down Counter - Verification

Verified 4-bit Up/Down Counter using Verilog Testbench in EDA Playground.

## What I Verified
- Reset functionality - Counter goes to 0
- Up Counting - 0 to 15
- Down Counting - 15 to 0
- Waveform analysis in EPWave

## Files
- counter_4bit.v - Design Under Test (DUT)
- tb_counter.v - Testbench

## Tools Used
- Verilog, EDA Playground, Icarus Verilog
